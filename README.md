# Azure技術PR

## 目指すキャリア
- クラウドの保守運用領域でキャリアを開始する。
- ID管理、ガバナンス、セキュリティ領域へ拡大する。
 
## 経歴
- CAEに関わるソフトのマニュアルを数百ページ作成し、判りやすい資料作成の方法を習得した。
- チームリーダーを６年間経験し、人との接し方、情報共有の仕方を習得した。
- これらの経験を、ドキュメント作成および、IT業務でのチームワークに活かす。
