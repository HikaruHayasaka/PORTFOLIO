# Azure Policy：割り当て（GUI）
## 1. 目的
Azure Policy を使用し、サブスクリプションまたはリソース グループに対してポリシーを割り当てる手順を理解する。

## 2. 設計
- 対象スコープ：任意のリソース グループ
- 割り当てるポリシー：組み込みポリシー（例：タグの強制、場所の制限など）
- 割り当て方法：Azure ポータル（GUI）

## 3. 手順（GUI）
### 3-1. Azure Policy 画面を開く
1. Azure ポータルへサインインする。
2. 画面上検索窓で検索 → **ポリシー** を選択する。
3. 「概要」画面が表示される。

<img src="../images/04-01-policy-01-overview.png" width="600">

### 3-2. ポリシー割り当ての開始
1. 左メニュー → **作成** → **割り当て** を選択する。
2. 上部の **＋ポリシーの割り当て** を押す。

<img src="../images/04-01-policy-02-assign-button.png" width="600">

### 3-3. スコープの設定
1. **基本情報タブ** → **スコープ** → **・・・** をクリック。
2. 任意のサブスクリプションを選択。（例：Azure subscription 1）
3. 任意のリソース グループを選択。（省略可）
4. **選択** をクリック。

<img src="../images/04-01-policy-03-scope.png" width="600">

### 3-4. ポリシー定義の選択
1. **ポリシー定義** → **・・・** をクリック。
2. 一覧から組み込みポリシーを選択。（例：`Require a tag on resources`（タグの強制））
   （選択できるポリシーは1つだけです）
3. **追加** をクリック。

### 3-5. 割り当て名の設定
1. 「割り当て名」を入力。（自動で入力される場合もある）
2. 説明が必要な場合は任意で入力。
3. **レビューと作成** → **作成** をクリック。

<img src="../images/04-01-policy-04-definition.png" width="600">

### 3-5. パラメーターの設定
1. パラメータータブを選択
2. 選択したポリシーに応じて、必要なパラメーターを入力する。
今回のポリシーは「タグの強制」のため、以下に代表的なタグを挙げる。
   - Environment（例：Dev / Test / Prod）
   - Owner（例：担当者名）
   - CostCenter（例：部門コード）
   - Project（例：プロジェクト名）
   - Department（例：部署名）
2. 入力後、**レビューと作成** → **作成** を押す。

<img src="../images/04-01-policy-05-parameters.png" width="600">

### 3-7. 割り当て結果の確認
1. 割り当て一覧に戻る。
2. 作成したポリシー割り当てが表示されていることを確認する。
3. 必要に応じて「コンプライアンス」画面で適用状況を確認する。

## 4. 結果
- 対象スコープにポリシーが割り当てられた。
- パラメーターが設定された状態でポリシーが適用される。
- コンプライアンス画面で評価結果を確認できる。

## 5. 学び
- Azure Policy の割り当て手順を理解した。
- スコープ → ポリシー定義 → パラメーター → 割り当て の流れを把握した。
- ガバナンス構成の基礎として、ポリシー適用の重要性を理解した。
