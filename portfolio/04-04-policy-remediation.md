# Non-compliant リソースの特定・是正
## 1. 目的
Azure Policy のコンプライアンス評価で非準拠と判定された既存リソースを特定し、修正タスクを使用して是正する手順を理解する。

## 2. 設計
- 対象ポリシー：`Add a tag to resources`（組み込みポリシー、Modify効果）
- 割り当てスコープ：既存の非準拠リソースを含むリソース グループ
- 対象リソース：Environmentタグが未設定の既存リソース（仮想マシン以外、課金なし）
- 是正方法：Azure ポータルの修正機能（修正タスク）

> **注意**
> 04-01で使用した `Append a tag and its value to resources` はAppend効果のポリシーであり、新規作成・更新時のみ適用されるため、既存の非準拠リソースを修正タスクで是正することができない。
> 既存リソースを是正するには、Modify効果またはDeployIfNotExists効果を持つポリシーが必要となるため、今回は `Add a tag to resources` を新たに割り当てる。

## 3. 手順
### 3-1. Modify効果を持つポリシーの割り当て、スコープの設定
1. Azure ポータルにサインイン。
2. 上部検索バーから、"ポリシー"を検索してクリック。
3. 左メニューから 作成 → 割り当て をクリック。
4. 上部の ポリシーの割り当て をクリック。
5. 基本情報タブ → スコープ → ・・・ をクリック。
6. サブスクリプションで対象のサブスクリプションを選択。
7. リソース グループで、非準拠リソースを含むリソース グループを選択。
8. 選択をクリック。

<img src="../images/04-04-policy-remediation-01-scope.png" width="600">

### 3-2. ポリシー定義の選択と割り当て名の設定
1. ポリシー定義 → ・・・ をクリック。
2. 一覧から `Add a tag to resources` を検索して選択。
3. 追加をクリック。
4. 割り当て名を確認。（自動で入力される場合もある）
5. パラメータータブを選択。
6. タグ名の値に `Environment` を入力。
7. タグ値の値に `PolicyTest` を入力。
8. レビューと作成 → 作成 をクリック。

<img src="../images/04-04-policy-remediation-02-parameters.png" width="600">

### 3-3. コンプライアンス画面で非準拠リソースを特定
1. 左メニューから コンプライアンス をクリック。
2. 割り当てた `Add a tag to resources` をクリック。
3. リソース コンプライアンスの一覧で、状態が 非準拠 のリソースを確認。
（対象のリソース `saalertdemo01` にEnvironmentタグが設定されておらず、非準拠と判定されている）
（コンプライアンスの反映には数十分かかる場合がある）

<img src="../images/04-04-policy-remediation-03-compliance.png" width="600">

### 3-4. 修正タスクの作成
1. 左メニューから 修正 をクリック。
2. 非準拠のポリシー タブで、対象の `Add a tag to resources` をクリック。
3. 「新しい修正タスクの作成」画面で、対象のリソースの一覧を確認。（既定ですべて選択されている）
4. 修正をクリック。

<img src="../images/04-04-policy-remediation-04-remediation-task.png" width="600">

### 3-5. 修正タスクの進捗確認
1. 修正タスク タブをクリック。
2. 作成したタスクをクリック。
3. 状態が 実行中 から 完了 に変わることを確認。
4. 対象のリソースの一覧で、各リソースの修正結果を確認。

<img src="../images/04-04-policy-remediation-05-progress.png" width="600">

### 3-6. 是正結果の確認
1. 左メニューから コンプライアンス をクリック。
2. 割り当てた `Add a tag to resources` をクリック。
3. 是正したリソースのコンプライアンスの状態が 準拠 に変わっていることを確認。
（コンプライアンスの反映には数十分かかる場合がある）

<img src="../images/04-04-policy-remediation-06-confirm.png" width="600">

## 4. 結果
- コンプライアンス画面から、Environmentタグが未設定の非準拠リソースを特定できた。
- Modify効果を持つポリシー `Add a tag to resources` を割り当て、修正タスクを実行することで、既存の非準拠リソースにタグを追加し是正できた。
- 是正後、対象リソースのコンプライアンスの状態が準拠に変わったことを確認した。

## 5. 学び
- 修正タスクはModify効果またはDeployIfNotExists効果を持つポリシーでのみ利用でき、AppendやDeny効果のポリシーでは既存リソースを是正できないと分かった。
- コンプライアンス画面で非準拠リソースを特定した後、修正 画面から手動で修正タスクを作成する必要があると理解した。
- 修正タスクの実行結果や、コンプライアンスの再評価には反映までにタイムラグがあるため、結果確認は時間を置いて行う必要があると学んだ。
